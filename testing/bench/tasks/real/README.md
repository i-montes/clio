# Tareas reales del banco

Aquí van las 10 tareas reales de la persona (D15): trabajo que de verdad le interesa que Clio haga, con éxito comprobable por una señal externa (una prueba que pasa, un archivo que existe, un valor exacto), nunca por lo que diga el modelo. Una tarea por archivo `.json`, con el formato de `../trivial/` (`id`, `input`, `check`, `max_steps`, `max_cost_micro_usd`, `max_duration_ms`).

Pendiente de la persona: elegirlas (tarea 067). El runner las carga solas cuando existan.
